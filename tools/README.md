# Narzędzia / External tools

## Polski

Repozytorium **nie dołącza** binariów FFmpeg i FFprobe. Ten katalog nie jest kopiowany automatycznie do output/publish. Aplikacja szuka **tools/ffmpeg.exe** i **tools/ffprobe.exe** przy **uruchomionym EXE**, a następnie w bezwzględnych katalogach PATH.

Wymagania: [docs/REQUIREMENTS.md](../docs/REQUIREMENTS.md). Budowanie: [docs/BUILD.md](../docs/BUILD.md). Pakowanie i licencje: [docs/PACKAGING.md](../docs/PACKAGING.md).

## English

The repository **does not bundle** FFmpeg or FFprobe executables. This source tools directory is not copied to build or publish output. The app looks for **tools/ffmpeg.exe** and **tools/ffprobe.exe** next to the **running EXE**, then in absolute PATH directories.

Requirements: [docs/en/REQUIREMENTS.md](../docs/en/REQUIREMENTS.md). Build: [docs/en/BUILD.md](../docs/en/BUILD.md). Packaging and licenses: [docs/en/PACKAGING.md](../docs/en/PACKAGING.md).
